Known cheat files

certain evidence · bans automatically

A file the game loads whose SHA-256 is on this list is a known cheat, whatever the file is called, wherever it sits and whether it is signed or not. The match is made here on the server from the hash the player's client reports for every loaded file; the list is never sent to a client. An entry applies to files reported after it was added, so a player already in a game is caught at the next start.
